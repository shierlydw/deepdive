# Asset index

Files are numbered in the order they appear in `index.html`.

- Home page and case study 1 use `img_N` / `video_N` — the existing convention.
- Case study 2 uses a separate `ds_img_N` / `ds_video_N` namespace, so none of
  its files can collide with what is already in the repo.

Format follows the image: `.png` where transparency is needed, `.jpg` otherwise.
